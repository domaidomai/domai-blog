这个项目本身就是现在这座博客站。它不是一套套模板后直接上线，而是围绕“长期写作也要有作品感”这个目标，一点点把结构和体验打磨出来。

## 这个项目解决什么

- 把技术文章和项目展示放进同一套信息架构
- 用 Markdown 保持低摩擦写作和长期维护
- 用静态部署把上线成本压到很低
- 在不引入后端的前提下补齐搜索、评论和 RSS

## 做了哪些部分

- 首页精选项目与最新文章联动
- 文章、项目、标签、归档和关于页
- 可搜索的静态内容索引
- GitHub Pages 自动部署
- 默认封面、深色模式和更完整的详情页呈现

## 为什么把它当成作品

因为这不是单纯的“个人博客搭建练习”，而是一套同时包含内容结构、视觉语言、部署流程和长期维护思路的完整站点方案。
