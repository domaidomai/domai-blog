知己把选测试、逐题作答、查看解析和保存报告串成完整流程，适合在手机上体验。

当前为试用版本。答案与报告保存在当前浏览器，建议下载留存；尚未完成大规模并发容量验收。

## 可以体验什么

- 八套测试，覆盖关系偏好、社交能量、性格探索和非官方趣味角色契合，共 186 道原创题目。
- 暂停后继续作答，返回修改答案。
- 查看分维度结果、回答依据、情境解析与可执行建议。
- 下载分享卡、完整报告长图、Markdown 和 JSON；通过浏览器打印保存 PDF。
- 在当前浏览器保留最近 30 份报告。

## 实现中的取舍

题库与计分规则独立管理，报告保存当时的题目、回答和解析快照，后续题库更新不会重写已有报告。

答案和历史保留在当前浏览器，没有云端答卷收集接口，也没有跨设备同步。后端负责题库发布与管理鉴权，使用 Node.js 内置能力和文件持久化，不依赖模型 API 生成报告。

## 如何验证

项目已有计分极值、反向题、无效输入、题库版本、管理鉴权和持久化等自动测试；验收记录包含作答、暂存恢复及报告导出流程。测试能验证程序按规则执行，题目含义与解析质量仍需人工评审和实际反馈。

## 当前边界

题目为原创探索版，未开展信效度或常模研究，结果用于自我观察与娱乐，不用于诊断。斩神主题属于非官方娱乐创作。

清除浏览器数据或更换设备会丢失本机历史；手机系统和内置浏览器的下载、打印行为仍需真机核对。目前没有付费、兑换码或云端账号。
